Lecture 5. CPA Security and Pseudorandom Functions

Need for Stronger Security

为什么我们需要比 IND-EAV 更强的安全性？考虑两个场景：

IND-MULT

我们回顾 \(\operatorname{PrivK}^{\mathrm{eav}}_{A,\Pi}(n)\) 不可区分性实验：攻击者每次看到一个密文，然后二选一猜测明文。如果对于任意 PPT 攻击者 \(A\)，都存在一个可忽略函数 \(\operatorname{negl}(n)\)，使得

\[ \Pr[ \operatorname{PrivK}^{\mathrm{eav}}_{A,\Pi}(n)=1 ] \leq \frac12+\operatorname{negl}(n) \]

则该方案具有单消息不可区分性

而现实中，密钥会被反复使用，因此对于多个密文，我们需要额外分析多密文是否会暴露明文关系

因此我们引入多消息窃听实验

\[ \operatorname{PrivK}^{\mathrm{mult}}_{A,\Pi}(n) \]

它的流程为：攻击者提交两组信息，保证 \(|m_{0,i}| = |m_{1,i}|\)

\[ \vec{M_0} = (m_{0,1}, \cdots, m_{0,t}) \\ \vec{M_1} = (m_{1,1}, \cdots, m_{1,t}) \]

挑战者生成密钥 \(k \leftarrow Gen(1^n)\)，并随机选择 \(b\in\{0,1\}\)（即随机选择 \(\vec{M_0}\) 或 \(\vec{M_1}\) 进行加密），令 \(c_i=\operatorname{Enc}_k(m_b,i)\)，由攻击者根据密文组 \(\vec{C} = (c_1,\cdots,c_t)\)猜测 \(b\) 的值，记作 \(b'\)

我们继续定义窃听模型下的多次加密计算不可区分性（Indistinguishable multiple encryptions in the presence of an eavesdropper）：对于任意 PPT 攻击者 \(A\)，都存在一个可忽略函数 \(\operatorname{negl}(n)\)，使得

\[ \Pr[\operatorname{PrivK}^{\mathrm{mult}}_{A,\Pi}(n)=1] \leq \frac12+\operatorname{negl}(n) \]

满足 IND-EAV 的加密方案不一定能满足多消息安全。我们以基于 PRG 的加密方案为例，依旧是 Two-Time Pad 攻击：对两条加密信息异或，可以得到两条原文的异或

具体的，我们令

\[ \vec{M_0} = (aa, aa) \\ \vec{M_1} = (aa, ab) \]

如果加密的是第一组，那么 \(c_1\oplus c_2 = 0\) 是显然的；否则 \(c_1 \oplus c_2 \ne 0\) 是显然的。此时 \(\Pr[\operatorname{PrivK}^{\mathrm{mult}}_{A,\Pi}(n)=1] = 1\)

以上：IND-EAV 无法得到 IND-MULT。只要加密算法是确定性的，那么它一定不符合 IND-MULT 下的安全

Chosen-Plaintext Attack

EAV 模型中，攻击者（窃听者）只能获得指定的明文；KPA 模型中，攻击者一直某些其他明文以及对应密文；而 CPA 模型中，攻击者可以主动提供明文并获取对应的密文。在最后一种情形下，攻击者得到最多的信息

我们提供一个加密预言机 \(\operatorname{Enc}_k(\cdot)\)，输入为明文，输出为密文，攻击者可以自适应多次查询结果。进一步的，我们给出 CPA 不可区分性实验 \(\operatorname{PrivK}^{\mathrm{cpa}}_{A,\Pi}(n)\)

相比直接提供两个等长明文，攻击者可以先使用 \(\operatorname{Enc}_k(\cdot)\) 观察任意多次的加密结果，然后再给出 \(m_0,m_1\)。挑战者依旧二选一明文并给出密文，攻击者可以在看到密文之后继续使用 \(\operatorname{Enc}_k(\cdot)\) 观察任意多次的加密结果，并最终给出自己的判断 \(b'\)

同理，如果对于任意 PPT 攻击者 \(A\)，都存在一个可忽略函数 \(\operatorname{negl}(n)\)，使得

\[ \Pr[ \operatorname{PrivK}^{\mathrm{cpa}}_{A,\Pi}(n)=1 ] \leq \frac12+\operatorname{negl}(n) \]

则该方案满足 CPA-Secure

显然，只要加密算法是确定性的，那么它一定不符合 CPA 安全：我只要在看到密文后，对 \(m_0\) 进行一次预言机查询，就可以判断密文来自 \(m_0\) 还是 \(m_1\)

上面两个场景都是对 EAV 场景的加强，攻击者通过获得更多的信息，使得当前的加密算法不再安全。具体的，CPA 情景蕴含于 MULT 情景，如果一个方案是 CPA 安全的，那么它一定是 IND-MULT 安全的（后面会说）

PRF

我们先从真正的随机函数说起：考虑一个函数

\[ f:\{0,1\}^{l_{in}} \to \{0,1\}^{l_{out}} \]

通常我们只需要考虑等长映射

\[ f:\{0,1\}^{n} \to \{0,1\}^{n} \]

这样的函数集合我们记为 \(\text{Func}_{n}\)，对于不同的 \(n\)，\(|\text{Func}_{n}|\) 的大小会如何膨胀？我们知道输入空间 \(|\{0,1\}^{n}| = 2^{n}\)，而对于每个输入，可以独立选择 \(2^n\) 个可能输出，因此

\[ |\text{Func}_{n}| = \underbrace{2^{n} \times 2^{n} \times \cdots \times 2^{n}}_{2^{n} \text{ times}} = 2^{n2^n} \]

正式的随机函数就是：从 \(\text{Func}_{n}\) 中均匀随机抽取一个函数，然后再之后的计算过程中始终使用这个函数：相同输入一定是相同输出；不同输入的输出独立均匀分布

现在我们引入带密钥的函数 \(F(k,x)\)，在本章中默认所有的 \(l_{?} = n\)：

\[ F: \{0,1\}^{l_{key}} \times \{0,1\}^{l_{in}} \to \{0,1\}^{l_{out}} \]

对于相同的密钥和输入，它的输出依旧是固定的；然而只要更换 \(k\)，它对相同输入的输出就是不可预测的

对于固定的 \(k\)，我们得到基于 \(k\) 的特定函数，记为 \(F_{k}(x)\)。简单来说

\[ F(k,x) = F_{k}(x) \]

即每一个密钥 \(k\) 都对应了一个具体的函数 \(F_k\)

函数空间的大小为 \(|\text{Func}_{n}| = 2^{n2^n}\)，而 \(F(k,x)\) 只能抽取其中的 \(2^{n}\) 个函数（由密钥空间决定），然而这样的函数依旧看上去随机，因为一个高效攻击者无法在多项式时间内检查单个带密钥函数的全部 \(2^n\) 个输入

由此，我们定义伪随机函数：给定多项式量级的输入 \(x_i\)，如果攻击者在观察

\[ F_k(x_1), F_k(x_2),\cdots,F_{k}(x_{poly(n)}) \]

后，在计算层面上与一个真正随机函数的对应结果不可区分，那么 \(F\) 就是伪随机函数（当然，\(F(k,x)\) 的计算得是多项式时间的）

区分器仅根据多项式个输入以及对应的输出，无法判断自己使用的是一个由短密钥生成的假随机函数，还是一个真正的随机函数

形式化的，令

\[ F: \{0,1\}^{n} \times \{0,1\}^{n} \to \{0,1\}^{n} \]

随机选择密钥 \(k\leftarrow \{0,1\}^n\)，以及 \(f \leftarrow \text{Func}_{n}\)

如果对于任意 PPT 区分器 \(D\)，都存在可忽略函数 \(\mu(n)\)，使得

\[ \begin{aligned} &\left| \Pr[D^{F_k(\cdot)}(1^{n})=1] -\Pr[D^{f(\cdot)}(1^{n})=1] \right|\leq\mu(n) \end{aligned} \]

那么 \(F\) 是伪随机函数

为什么我们希望达到这样的计算结果？注意到 \(F(k,x)\) 只能在 \(|\text{Func}_{n}| = 2^{n2^n}\) 中采样非常小部分的函数，但是 PRF 能够做到让区分器看不出来自己其实是从一个密钥小空间采样的函数，而不是从完整的函数空间中采样的函数

这就是 PRF 的价值：它以小乱大，用伪随机的方式实现了计算安全上的等价真随机（不可区分）

一个失败的 PRF 构造往往会让它的函数族 \(F_k\) 存在相似的特征，导致不同的输入在输出上存在规律

CPA-Secure

我们现在有了 PRF 可以产生计算上与随机函数不可区分的输出，现在可以构造 CPA-Secure 的方案了

给出加密方案 \(\Pi=(\operatorname{Gen},\operatorname{Enc},\operatorname{Dec})\)，以及安全参数 \(n\)，以及一个安全的 PRF \(F\)

我们均匀随机采样 \(k\)，使用 Gen 执行密钥生成。然后给定明文 \(m\)，随机选择 \(r\) 并计算 \(F_k(r)\) 的值，进行加密

\[ \text{Enc}_k(m) = (r,F_{k}(r) \oplus m) \]

这里 \(r\) 不需要保密，可以直接放到密文中。解密同理

\[ \text{Dec}_k(r,s) = F_{k}(r) \oplus s \]

显然它是正确的

相比较我们之前进行 PRG 加密

\[ \text{Enc}_k(m) = G(k) \oplus m \]

它每次解密使用相同的掩码 \(G(k)\)，而现在我们使用不同的掩码 \(F_{k}(r_1),F_{k}(r_2),\cdots\)，有效避免了不同输入的输出存在关联性

我们假设 \(r\) 的碰撞概率极低

Proof by Hybrid Argument

我们如何证明：在上述情境下，只要 \(F\) 是一个安全的 PRF，可以推导出 \(\Pi\) 是 CPA-secure？我们需要使用混合实验论证（它也用到了规约思想）

我们记使用了 PRF 的原始方案 \(\Pi=(\operatorname{Gen},\operatorname{Enc},\operatorname{Dec})\)，满足

\[ \text{Enc}_k(m) = (r,F_{k}(r) \oplus m) \]

现在构造一个理想化方案 \(\tilde{\Pi}\)，它的加密采用真正的随机函数

\[ \text{Enc}_k(m) = (r,f(r) \oplus m) \]

我们证明它在 CPA 攻击模型中是计算不可区分的。反设存在一个 PPT 攻击者 \(A\) 可以区分两者输出，那么就有对应的区分器 \(D\)。具体的，\(D\) 得到一个预言机 \(Oracle(\cdot)\)，它可能实现为 \(F_k\) 也可能实现为 \(f\)

如果 \(A\) 可以区分 \(\Pi\) 和 \(\tilde\Pi\)，那么就说明 \(D\) 能够区分 \(F_k\) 和 \(f\)，而根据 PRF 的定义，后者是不可能的，因此 \(A\) 不可能区分 \(\Pi\) 和 \(\tilde\Pi\)

\[ \left| \Pr[\text{PrivK}^{\text{cpa}}_{\mathcal{A}, \Pi} = 1] - \Pr[\text{PrivK}^{\text{cpa}}_{\mathcal{A}, \tilde{\Pi}} = 1] \right| \leq \text{negl}_1(n) \tag{1} \]

接下来我们想进一步分析真正随机函数下的 CPA 安全性，即尝试证明（其中 \(q(n)\) 为攻击者查询的多项式次数上界）

\[ \Pr[\text{PrivK}^{\text{cpa}}_{\mathcal{A}, \tilde{\Pi}} = 1] \leq \frac{1}{2} + \text{negl}_2(n) \]

对于一个尚未查询过的新输入 \(r_i\)，真随机函数输出的 \(f(r_i)\) 就是完全独立、均匀随机的字符串。这等同于每次加密都使用 OTP 方案，显然猜对概率严格等于 \(1/2\)

在共计 \(q(n)\) 次的已知明文查询（每次生成 \(r_i\)），假设挑战时使用的随机值为 \(r^{\ast}\)，则

\[ \Pr[r_i = r^{\ast}] = \dfrac{1}{2^n} \]

而至少存在一次碰撞的概率为

\[ \begin{aligned} \Pr[\mathrm{Match}] &=\Pr\left[\bigcup_{i=1}^{q(n)}\{r_i=r^*\}\right]\\ &\leq\sum_{i=1}^{q(n)}\Pr[r_i=r^*]\\ &=\frac{q(n)}{2^n} \end{aligned} \]

而 \(q(n)/2^n\) 是一个可忽略函数

根据全概率公式，我们记 \(W=\{\operatorname{PrivK}^{\mathrm{cpa}}_{\mathcal A,\widetilde\Pi}=1\}\)，则

\[ \begin{aligned} \Pr[W] ={}&\Pr[W\mid\neg\mathrm{Match}] \Pr[\neg\mathrm{Match}]\\ &+\Pr[W\mid\mathrm{Match}] \Pr[\mathrm{Match}] \end{aligned} \]

未碰撞时，\(\Pr[W\mid\neg\mathrm{Match}]=\frac12\)，碰撞时直接取 \(\Pr[W\mid\mathrm{Match}]\leq1\)

代入上式：

\[ \begin{aligned} \Pr[W] &\leq\frac12\Pr[\neg\mathrm{Match}] +\Pr[\mathrm{Match}]\\ &\leq\frac12+\Pr[\mathrm{Match}]\\ &\leq\frac12+\frac{q(n)}{2^n} \end{aligned} \]

因此

\[ \Pr[\operatorname{PrivK}^{\mathrm{cpa}}_{\mathcal A,\widetilde\Pi}(n)=1] \leq\frac12+\frac{q(n)}{2^n} \tag{2} \]

结合两个结论式 \((1),(2)\)，我们得到

\[ \Pr[\operatorname{PrivK}^{\mathrm{cpa}}_{\mathcal A,\Pi}(n)=1] \leq \frac12+\frac{q(n)}{2^n}+\operatorname{negl}(n) \]

而 \(q(n)/2^n\) 是一个可忽略函数，则

\[ \Pr[\operatorname{PrivK}^{\mathrm{cpa}}_{\mathcal A,\Pi}(n)=1] \leq\frac12+\operatorname{negl}'(n) \]

以上，我们完成了证明：

\[ F\text{ is a PRF} \Longrightarrow \Pi\text{ is CPA-secure} \]

Multiple Encryptions

我们直接给出一个结论：单个挑战密文在 CPA 环境下安全，那么它对于多个挑战密文的情形也是 CPA 安全的

我们依旧利用 Hybrid Argument 证明

假设攻击者需要区分：

\[ \vec M_0=(m_{0,1},\ldots,m_{0,t}) \]

和：

\[ \vec M_1=(m_{1,1},\ldots,m_{1,t}) \]

我们构造 \(t+1\) 个混合实验（从 0 计数），其中第 0 个实验为

\[ H_0= (\mathrm{Enc}_k(m_{0,1}),\ldots,\mathrm{Enc}_k(m_{0,t})) \]

最后一个实验为

\[ H_t= (\mathrm{Enc}_k(m_{1,1}),\ldots,\mathrm{Enc}_k(m_{1,t})) \]

对于中间的实验，我们让每一个实验相比上一个实验，只将第 \(i\) 条密文的明文选择从 \(\vec M_0\) 替换为 \(\vec M_1\) 的对应值

此时相邻的两个实验只有单信息不同，退化为单信息 CPA。如果攻击者能够有效区分任意相邻的两个实验，那么就可以构造一个单消息 CPA 攻击者：把第 \(i\) 条消息放进自己的 CPA 挑战，其余位置通过加密预言机生成，显然这不满足已知的单消息 CPA 安全。因此相邻实验之间的区分优势都是可忽略的

当 \(t\) 是多项式规模时，有

\[ \begin{aligned} &\left| \Pr[\mathcal A(H_0)=1] - \Pr[\mathcal A(H_t)=1] \right|\\ &\leq\sum_{i=1}^{t} \left| \Pr[\mathcal A(H_{i-1})=1] - \Pr[\mathcal A(H_i)=1] \right|\\ &\leq t\cdot\operatorname{negl}(n) \end{aligned} \]

多项式与可忽略函数的乘积仍然可忽略，因此上述结果依旧是可忽略的

证明思路就是想办法让多消息挑战的可忽略程度表述为多项式个单消息挑战的可忽略程度之和

Existence of PRFs

PRF 能否被实际构造出来？我们先引入函数映射的一个特殊情况：置换

对于一个等长函数 \(f:\{0,1\}^n\to\{0,1\}^n\)，如果它满足一一对应的双射关系，即不同输入一定得到不同输出，那么称 \(f\) 是一个置换（相比单纯的函数不能产生多对一的碰撞）

我们记所有 \(n\)-bit 置换构成的集合为 \(\text{Perm}_n\)。计算这个集合的大小：一共有 \(2^n\) 个输入，第一个输入有 \(2^n\) 种输出可以选择，第二个输入只能选择剩下的 \(2^n-1\) 个输出，以此类推，因此

\[ |\text{Perm}_n|=2^n\cdot(2^n-1)\cdots 1=(2^n)! \]

与之前的随机函数对比

\[ |\text{Func}_n|=2^{n2^n} \\ |\text{Perm}_n|=(2^n)! \]

显然 \(\text{Perm}_n\subseteq\text{Func}_n\)，置换实际上就是满足双射约束的特殊函数

进一步的，我们引入随机置换（Random Permutation），均匀随机选择 \(f\leftarrow\mathrm{Perm}_n\)，并在后续计算中始终使用它

现在考虑一个带密钥置换 \(F(k,x)\)，对于任意固定的密钥 \(k\)，映射 \(F_k\) 都必须是一个置换

\[ F:\{0,1\}^{\ell_{\mathrm{key}}} \times\{0,1\}^{\ell_{\mathrm{in}}} \rightarrow\{0,1\}^{\ell_{\mathrm{in}}} \]

我们将输入和输出的长度称为分组长度（Block Length），记为 \(\ell_{in}\)，并要求正向计算 \(F_k(x)\) 与逆向计算 \(F_k^{-1}(y)\) 都是多项式时间的

我们希望它和之前的 PRF 一样具有不可区分性，只是现在比较的对象变成了真正的随机置换

形式化的，随机选择密钥 \(k\leftarrow\{0,1\}^n\)，以及 \(f\leftarrow\text{Perm}_n\)，如果对于任意 PPT 区分器 \(D\)，都存在可忽略函数 \(\mu(n)\)，使得

\[ \left| \Pr[D^{F_k(\cdot)}(1^n)=1] - \Pr[D^{f(\cdot)}(1^n)=1] \right|\leq\mu(n) \]

那么 \(F\) 就是伪随机置换（Pseudorandom Permutation，PRP）

PRF 要求区分器无法分辨 \(F_k\) 和真随机函数，而 PRP 要求区分器无法分辨 \(F_k\) 和真随机置换。这里的 PRP 定义只给区分器提供正向预言机，并没有提供 \(F_k^{-1}\) 的查询能力

PRP and PRF

如果 \(F\) 是安全的 PRP，并且它的分组长度 \(\ell_{in}\geq n\)（\(n\) 为安全参数），则 \(F\) 也是安全的 PRF，即使 PRF 允许碰撞，而 PRP 不允许碰撞

假设区分器拥有一个预言机 \(O(\cdot)\)，它可能来自 \(\text{Perm}_n\)，也可能来自 \(\text{Func}_n\)。区分器选取两个不同输入 \(x_1\ne x_2\)，查询结果为

\[ y_1=O(x_1) \\ y_2=O(x_2) \]

如果 \(y_1=y_2\)，那么可以肯定 \(O\) 不是随机置换，因为置换必须满足一一对应关系。但是在真随机函数下，这个事件发生的概率只有

\[ \Pr[f(x_1)=f(x_2)]=\frac1{2^n} \]

现在考虑查询 \(q(n)\) 个不同输入。在随机函数下，任意一对不同输入的输出碰撞概率为 \(2^{-n}\)，而这样的输入对共有 \(\binom{q(n)}2\) 个，因此利用 Union Bound 得到

\[ \begin{aligned} \Pr[\text{Collision}] & = 1-\prod_{i=0}^{q-1}\left(1-\frac{i}{2^n}\right)\\ &\leq\binom{q(n)}2\cdot\frac1{2^n}\\ &=\frac{q(n)(q(n)-1)}{2^{n+1}} \end{aligned} \]

如果没有发生输出碰撞，随机函数在这些不同输入上的输出分布，就和随机置换的查询结果相同，因此攻击者只有在碰撞事件出现时才可能利用两者之间的结构差异

由于 PPT 区分器的查询次数 \(q(n)\) 是多项式，因此

\[ \frac{q(n)(q(n)-1)}{2^{n+1}} \]

是一个可忽略函数

所以在多项式数量的正向查询下，随机置换与随机函数之间的差别在计算上不可察觉

我们继续将这个结论与 PRP 的安全性结合。考虑三种预言机：

\[ F_k(\cdot) \quad\longrightarrow\quad f_{\text{perm}}(\cdot) \quad\longrightarrow\quad f_{\text{func}}(\cdot) \]

其中第一个是伪随机置换，第二个是真随机置换，第三个是真随机函数

  • 根据 PRP 的定义，第一个与第二个计算不可区分
  • 根据刚才的碰撞概率分析，第二个与第三个在多项式次查询下计算不可区分

因此利用三角不等式，可以得到

\[ \begin{aligned} &\left| \Pr[D^{F_k(\cdot)}(1^n)=1] - \Pr[D^{f_{\text{func}}(\cdot)}(1^n)=1] \right|\\ &\leq \operatorname{negl}(n) + \frac{q(n)(q(n)-1)}{2^{n+1}} \end{aligned} \]

右边是两个可忽略函数之和，因此我们证明了

\[ F\text{ is a PRP} \Longrightarrow F\text{ is a PRF} \]

Strong PRP

我们之前定义的 PRP 只允许攻击者查询正向函数 \(F_k(x)\)，但是一个置换还拥有逆函数 \(F_k^{-1}(y)\)，实际密码系统往往也需要同时提供正向和逆向运算

因此我们进一步加强攻击模型：允许区分器同时获得两个预言机

\[ F_k(\cdot),\quad F_k^{-1}(\cdot) \]

如果在这种情况下，它依旧无法区分一个带密钥置换与真正随机置换，就称其为强伪随机置换（Strong Pseudorandom Permutation，Strong PRP）

形式化的，随机选择 \(k\leftarrow\{0,1\}^n\) 和 \(f\leftarrow\text{Perm}_n\)，若对于任意 PPT 区分器 \(D\)，都存在可忽略函数 \(\mu(n)\)，使得

\[ \begin{aligned} \big| &\Pr[D^{F_k(\cdot),F_k^{-1}(\cdot)}(1^n)=1]\\ -&\Pr[D^{f(\cdot),f^{-1}(\cdot)}(1^n)=1] \big|\leq\mu(n) \end{aligned} \]

则 \(F\) 是 Strong PRP

显然 Strong PRP 的攻击者拥有更强的能力，因此

\[ \text{Strong PRP}\Longrightarrow\text{PRP} \]

Block Cipher

PRP 与实际加密有什么关系？我们之前在流密码一章中提到，除了 Stream Cipher，我们还可以使用 Block Cipher（分组密码）实现对称加密

分组密码会接收固定长度的输入分组，并在密钥控制下输出一个等长分组，同时支持逆运算。比如 AES 的分组长度固定为 128-bit，密钥长度可以是 128/192/256-bit

对于固定的密钥 \(k\)，AES 定义了一个从 \(\{0,1\}^{128}\) 到自身的置换，并可以通过对应的逆函数解密。因此分组密码可以被看作带密钥置换，安全的设计目标是使它在计算上表现为一个 PRP（通常还希望满足 Strong PRP）

需要注意：一个分组密码满足 PRP 安全，不代表直接对消息的每个分组分别使用它加密就满足 CPA 安全

例如，直接使用分组密码 \(F_k\) 加密每个分组，有

\[ c_i=F_k(m_i) \]

对于固定密钥，相同明文分组一定得到相同密文分组，因此这种 ECB 方式是确定性的，仍然暴露了明文的重复结构

为了安全地加密较长的消息，我们还需要将分组密码与合适的工作模式（Mode of Operation）结合，比如 CBC、CTR 等。它们的安全性还依赖于模式本身的构造以及随机数 / IV 的使用方式

PRFs and PRGs

最后讨论 PRF 和 PRG 的关系，我们之前已经学过：PRG 使用短种子生成一个较长的伪随机字符串，而 PRF 通过短密钥生成一个看起来像随机函数的映射

我们先从 PRF 构造 PRG：假设 \(F\) 是安全 PRF，固定一个随机种子 \(s\in\{0,1\}^n\) 作为密钥，选择 \(\ell\) 个互不相同的 \(n\)-bit 输入，定义

\[ G(s)=F_s(1)||F_s(2)||\cdots||F_s(\ell) \]

数字 \(1,2,\cdots,\ell\) 编码为互不相同的 \(n\) 比特输入。由于每个 \(F_s(i)\) 都有 \(n\) 个 bit，因此

\[ G:\{0,1\}^n\to\{0,1\}^{n\ell} \]

当 \(\ell>1\) 时，就实现了从 \(n\) bit 种子扩展到 \(n\ell\) bit 输出

为什么它是 PRG？我们依旧考虑一个混合替换：如果把 \(F_s\) 替换成真正的随机函数 \(f\)，那么对于不同输入 \(1,2,\cdots,\ell\)，每一个 \(f(i)\) 都是独立均匀随机的 \(n\)-bit 字符串，因此拼接结果就是一个真正均匀随机的 \(n\ell\)-bit 字符串

而如果攻击者能够区分 \(G(s)\) 与这样一个真随机字符串，那么就可以构造区分器来区分 \(F_s\) 和 \(f\)，违反 PRF 的定义

因此

\[ \text{PRF}\Longrightarrow\text{PRG} \]

反过来，我们能否利用 PRG 构造 PRF？一个直观想法是：先通过 PRG 生成足够长的伪随机比特串，然后根据输入 \(x\) 的值，截取其中对应的一段作为 \(F_k(x)\)

设 \(G(k)\) 生成比特串

\[ G(k)=y_0y_1y_2\cdots \]

初步的尝试是：使用 PRG 输出切片

对于输出长度为 \(t(n)\) 的函数，我们将 \(x\in\{0,1\}^n\) 解释为一个整数，定义 $$ F_k(x) = y_{x\cdot t(n)} y_{x\cdot t(n)+1} \cdots y_{x\cdot t(n)+t(n)-1} $$

也就是说，将 PRG 输出按 \(t(n)\) bit 分组，每个不同的 \(x\) 对应其中一组。这样就能够利用 PRG 给不同的函数输入分配伪随机输出

不过这里有一个效率问题：\(x\) 有 \(2^n\) 种可能取值，为了完整覆盖所有输入，PRG 必须产生至少

\[ t(n)\cdot 2^n \]

个 bit，这个长度相对于安全参数 \(n\) 是指数级的，因此上面这种直接切片的方法无法作为标准意义下的高效 PRF 构造

GGM Construction

Goldreich–Goldwasser–Micali（GGM）Construction 是一个在多项式内构造 \(\text{PRG}\Longrightarrow\text{PRF}\) 的方法

我们考虑一个安全的 PRG，它将 \(n\)-bit 种子扩展为 \(2n\)-bit 输出

\[ G:\{0,1\}^n\to\{0,1\}^{2n} \]

将输出均分为两个 \(n\)-bit 字符串，分别记为 \(G_0(s)\) 和 \(G_1(s)\)

\[ G(s)=G_0(s)||G_1(s) \]

这里 \(G_0,G_1\) 都是确定性函数，可以根据一个输入 bit 选择其中一个输出。比如给定 \(b\in\{0,1\}\)，则 \(G_b(s)\) 表示当 \(b=0\) 时取前半部分，当 \(b=1\) 时取后半部分

我们使用 \(n\)-bit 的 \(k\) 作为 PRF 密钥，并将输入 \(x\in\{0,1\}^n\) 写成

\[ x=x_1x_2\cdots x_n \]

从 \(k\) 开始，根据 \(x\) 的每一个 bit 依次执行 \(G_0\) 或 \(G_1\)

\[ \begin{aligned} s_0&=k\\ s_i&=G_{x_i}(s_{i-1}),\qquad i=1,\ldots,n\\ F_k(x)&=s_n \end{aligned} \]

所以完整的构造为

\[ F_k(x_1x_2\cdots x_n) = G_{x_n}\left( G_{x_{n-1}}\left( \cdots G_{x_2}(G_{x_1}(k))\cdots \right)\right) \]

比如 \(x=011\)，那么计算顺序就是

\[ F_k(011)=G_1(G_1(G_0(k))) \]

我们可以将这个过程理解为一棵深度为 \(n\) 的二叉树：根结点保存 \(k\)，对于保存了 \(s\) 的结点，它的左子结点是 \(G_0(s)\)，右子结点是 \(G_1(s)\)

输入 \(x\) 就是在指定从根到叶子的路径：遇到 0 向左，遇到 1 向右，最终到达的叶子结点保存的值就是 \(F_k(x)\)

虽然整棵树一共有 \(2^n\) 个叶子，但是计算一个确定的 \(F_k(x)\) 时，根本不需要把整棵树都生成出来，只需要沿着 \(x\) 指定的路径向下计算，每一层执行一次 \(G\)

因此单次函数计算只需要 \(n\) 次 PRG 调用，是多项式时间的

并且对于固定的 \(k,x\)，整条路径和最终结果都固定，所以它首先满足一个带密钥函数的基本要求。现在需要证明它进一步满足 PRF 的不可区分性

Proof by Hybrid Argument

我们希望证明：如果 \(G\) 是安全 PRG，那么 \(F_k\) 与真正随机函数计算不可区分

形式化的，对于任意 PPT 区分器 \(D\)，需要证明

\[ \left| \Pr[D^{F_k(\cdot)}(1^n)=1] - \Pr[D^{f(\cdot)}(1^n)=1] \right| \leq\operatorname{negl}(n) \]

其中 \(k\leftarrow\{0,1\}^n\)，\(f\leftarrow\mathrm{Func}_n\)

直接分析整棵树比较困难，因为它有指数数量的结点，而区分器可以自适应查询多个不同输入。我们依旧使用 Hybrid Argument：逐层将由 \(G\) 产生的结点值替换为真正均匀随机的字符串

我们构造 \(n+1\) 个混合实验 \(H_0,H_1,\ldots,H_n\)

对于第 \(i\) 个实验 \(H_i\)，在深度为 \(i\) 的那一层，让每个结点的值分别独立均匀地取自 \(\{0,1\}^n\)，之后的所有层仍然按照 \(G_0,G_1\) 的规则向下生成

这里的 \(H_i\) 表示一整个函数的分布；区分器只能通过查询输入来得到对应的叶子输出，而不能直接查看树中间的结点

我们先考虑两个端点：

  • \(H_0\)：只有根结点随机选择 \(k\)，下面所有结点都通过 \(G\) 计算，因此得到的就是原始的 \(F_k\)
  • \(H_n\)：所有叶子结点都独立均匀随机，因此对于不同输入，输出相互独立且均匀，而相同输入始终对应同一个叶子，这恰好就是真正随机函数

因此我们只需要证明相邻的 \(H_i,H_{i+1}\) 计算不可区分

先暂时考虑一个更简单的问题：如果 \(G\) 是安全 PRG，那么多次独立运行 \(G\) 产生的结果，与同样数量的独立真随机字符串是否不可区分？

假设共有 \(q=q(n)\) 次输出，其中 \(q\) 是多项式。定义

\[ \begin{aligned} Y_0&=G(s_1)||G(s_2)||\cdots||G(s_q)\\ Y_q&=r_1||r_2||\cdots||r_q \end{aligned} \]

这里每个 \(s_i\) 都是独立均匀的 \(n\)-bit 种子，每个 \(r_i\) 都是独立均匀的 \(2n\)-bit 字符串

我们构造 \(q+1\) 个中间分布 \(Y_j\)，其中前 \(j\) 段改为真随机，剩余部分依旧来自 PRG

\[ Y_j= r_1||\cdots||r_j|| G(s_{j+1})||\cdots||G(s_q) \]

相邻两个分布 \(Y_{j-1}\) 和 \(Y_j\) 只有第 \(j\) 段不同，其余部分的生成方式完全相同

如果存在 PPT 区分器 \(A\) 能以不可忽略的优势区分 \(Y_0\) 与 \(Y_q\)，我们就可以构造 PRG 区分器 \(B\)

具体的，\(B\) 获得一个未知来源的 \(2n\)-bit 字符串 \(w\)，它可能是 \(G(s)\)，也可能是真随机字符串。\(B\) 均匀随机选择 \(j\in\{1,\ldots,q\}\)，自己生成前 \(j-1\) 段真随机字符串和后 \(q-j\) 段 PRG 输出，再将 \(w\) 放到第 \(j\) 段，拼接后交给 \(A\)

  • 如果 \(w\) 来自 PRG，那么 \(A\) 看到的是 \(Y_{j-1}\)
  • 如果 \(w\) 来自真随机，那么 \(A\) 看到的是 \(Y_j\)

记 \(\alpha_j=\Pr[A(Y_j)=1]\)，根据全概率公式与求和消去中间项

\[ \begin{aligned} &\Pr[B(r)=1]-\Pr[B(G(s))=1]\\ &=\frac1q\sum_{j=1}^{q}(\alpha_j-\alpha_{j-1})\\ &=\frac{\alpha_q-\alpha_0}{q} \end{aligned} \]

由于 \(B\) 是 PPT 区分器，而 \(G\) 是安全 PRG，左边的绝对值是可忽略函数。又因为 \(q(n)\) 是多项式，所以

\[ |\alpha_q-\alpha_0| \leq q(n)\cdot\operatorname{negl}(n) \]

依旧是可忽略函数

这就说明：多项式个独立 PRG 输出，与同样数量的独立真随机字符串计算不可区分

现在回到 GGM 的二叉树。考虑相邻的两个实验 \(H_i,H_{i+1}\)

在 \(H_i\) 中，深度 \(i\) 的每个结点保存独立均匀随机的 \(n\)-bit 值 \(s\)，它的两个子结点分别保存

\[ G_0(s),\quad G_1(s) \]

而在 \(H_{i+1}\) 中，深度 \(i+1\) 的所有结点都直接独立均匀随机生成

因此，对于深度 \(i\) 的一个结点，两个实验之间的差异正好是将

\[ G(s)=G_0(s)||G_1(s) \]

替换为一个均匀随机的 \(2n\)-bit 字符串

这个替换与刚才证明的多次 PRG 输出不可区分性完全对应

但是还有一个问题：深度 \(i\) 的结点最多有 \(2^i\) 个，如果真的生成整棵树，仍然可能需要指数时间

我们注意到，PPT 区分器 \(D\) 最多只能进行 \(q(n)\) 次函数查询。每条输入 \(x=x_1\cdots x_n\) 在深度 \(i\) 只对应一个前缀

\[ x_1x_2\cdots x_i \]

因此实际被访问到的深度 \(i\) 的结点最多只有 \(q(n)\) 个，而不是 \(2^i\) 个

我们可以按需生成并缓存结点的值：当某个长度为 \(i\) 的前缀第一次出现时，才为它的两个子结点分配一组 \(2n\)-bit 值；再次遇到相同前缀时，直接使用之前保存的结果，之后沿着剩下的输入 bit 计算 \(G\)，直到得到叶子输出

这样就能够用多项式时间模拟相邻的混合实验，并且保证相同输入得到相同输出

具体的，构造一个区分器 \(A'\)，它接收 \(q(n)\) 段未知来源的 \(2n\)-bit 字符串，并随机选择一个层数 \(i\in\{0,\ldots,n-1\}\)

当 \(D\) 查询一个新的长度为 \(i\) 的前缀时，\(A'\) 就拿出下一段字符串，把前后两半分别作为该结点的左、右子结点，并继续按照 GGM 的规则向下计算。如果这个前缀已经出现过，则复用之前的值

  • 若输入 \(A'\) 的每段字符串都是独立的 PRG 输出，那么模拟的就是 \(H_i\)
  • 若输入 \(A'\) 的每段字符串都是独立真随机，那么模拟的就是 \(H_{i+1}\)

特别注意，同一个前缀的两个子结点必须来自同一段 \(2n\)-bit 字符串，不能在每次函数查询时重新生成，否则会破坏随机函数对相同输入输出一致的性质

记

\[ \beta_i=\Pr[D^{H_i(\cdot)}(1^n)=1] \]

由于 \(A'\) 均匀随机选择 \(i\)，我们同样得到

\[ \begin{aligned} &\Pr[A'(r_1||\cdots||r_q)=1]\\ &\qquad-\Pr[A'(G(s_1)||\cdots||G(s_q))=1]\\ &=\frac1n\sum_{i=0}^{n-1}(\beta_{i+1}-\beta_i)\\ &=\frac{\beta_n-\beta_0}{n} \end{aligned} \]

而我们刚才已经证明，多项式个独立 PRG 输出与真随机字符串不可区分，所以左边的绝对值是可忽略函数。乘上多项式 \(n\) 之后仍然可忽略，因此

\[ |\beta_n-\beta_0| \leq n\cdot\operatorname{negl}(n) \]

结合 \(H_0\) 和 \(H_n\) 的定义

\[ \begin{aligned} &\left| \Pr[D^{F_k(\cdot)}(1^n)=1] - \Pr[D^{f(\cdot)}(1^n)=1] \right|\\ &\leq\operatorname{negl}'(n) \end{aligned} \]

以上，我们完成了证明：

\[ G\text{ is a PRG} \Longrightarrow F\text{ is a PRF} \]
