Ch1. Finite Automata

前置定义

描述有限自动机 Finite Automaton，它是一个形式化的系统，只会记得有限数量的信息：

  • 信息描述为状态 state
  • 状态根据输入 inputs 而发生转移
  • 用于描述上述状态转移的规则称之为 transitions

被自动机 \(A\) 接受（在读入所有的 inputs 后，状态机抵达一个终结状态）的字符串（一系列 inputs）集合被称为 A 的语言 language，记为 \(L(A)\)

不同的最终状态集合对应了不同的 language，因此 \(L(A)\) 可以简单描述为“决定最终状态的字符串集合”

我们从符号化的角度进行形式化描述

符号集 alphabet 是任意的有限符号集合（可以使用于自动机，比如 ASCII）。对于符号集 \(\Sigma\)，一个字符串 string 中的每个元素都应该属于 \(\Sigma\)，并且不适用逗号等进行分隔

字符串的长度是它包含的位置数（可以简单理解为字符个数）；特别的，记 \(\epsilon\) 表示为长度为 \(0\) 的字符串，简称空串（有时写作 \(\{\}\)）

我们记 \(\Sigma^\ast\) 为由 \(\Sigma\) 可构造的所有字符串集合，而 language 就是 \(\Sigma\) 的一个子集合

比如：

\[ \{0,1\}^\ast = \{\epsilon, 0, 1, 00, 01, 10, 11, 000, 001, . . . \} \]

注意到 \(0\) 既可以看作一个 string，又可以看作一个 symbol，它的实际类型取决于上下文

另外的，对于小写英文字母，一个常用的约定是：前面的 \(a, b, c, \cdots\) 表示 symbols，用后面的 \(\cdots, w, x, y, z\) 表示 strings。这个约定在后面会经常使用

DFA

定义

确定性有限自动机 Determined Finite Automaton 包含五个要素

  • 有限大小的状态集 \(Q\)
  • 字母表 \(\Sigma\)
  • 转移函数 \(\delta\)，我们记 \(\delta(q, a) =p\) 表示状态 \(q\) 收到输入 \(a\) 后进入状态 \(p\)
  • \(\delta\) 是全函数 (total function)：总有“下一个状态”，可以使用 dead state 描述不会抵达的状态，比如应用于某个终结状态的下一个状态
  • 起始状态 \(q_0\)
  • 终结状态集 \(F\)

记一个正式的 DFA 为 \(A= (Q, \Sigma, \delta, q_0, F)\)

DFA 的确定性体现在：转移函数的结果唯一，即在某个状态下，对同一个输入只会有唯一的下一个状态

给出一个图表示的例子，它接受以 ing 结尾的串（否则在完全读取后抵达不了用双圈表示的终结状态，不被接受）

同时还有转移表的形式（这个在数字逻辑课的时序逻辑分析中已经有所讲解）

当前状态 \ 输入 i n g not i/n/g
N (nothing) I N N N
I (Saw i) I IN N N
IN (Saw in) I N * ING N
*ING (Saw ing) I N N N

其中标注 * 的状态为终结状态（可接受状态）

扩展转移函数

记 \(\delta(q, a) =p\) 表示状态 \(q\) 收到输入 \(a\) 后进入状态 \(p\)。进一步的，我们将单个输入 \(a\) 扩展到完整字符串 \(w\)，因为 DFA 每一步转移是确定的，则经过字符串 \(w\) 的多轮转移，结果也是确定的

因此定义扩展转移函数 \(\hat\delta\)（delta-hat，或者 \(\delta^\ast\)），对 \(\hat\delta(q,w)\) 的计算方式是：依次读取输入 \(w\) 的每个符号，并进行相应的转移

形式化的：

\[ \hat{\delta}(q, \epsilon) = q \\ \hat{\delta}(q, wa) = \delta( \hat{\delta}(q, w), a ) \]

注意到定义自洽性，我们实际使用时不会区分 \(\delta\) 和 \(\hat\delta\)，也就是说转移函数默认自带扩展属性

我们用转移函数描述 \(L(A)\)：

\[ L(A)=\{w \in \Sigma^\ast∣δ(q_0, w)\in F\} \\ w \in L(A) \iff \delta(q_0, w) \in F \]

Proofs of Set Equivalence

DFA 可以用于建模一个数学描述，我们期望证明：一个由 DFA 定义的语言，与一个由数学描述定义的字符串集合，实际上是同一个集合（即实现了逻辑等价的建模）

给定一个 DFA：\(A=(Q,Σ,δ,q_0,F)\)，给出语言：

\[ S = L(A)=\{w \in \Sigma^\ast∣δ(q_0, w)\in F\} \]

然后给出数学描述的语言，其中 \(P(w)\) 是描述性的数学性质：

\[ T =\{w \in \Sigma^\ast∣P(w)\} \]

我们想要证明

\[ S = T \]

为了更好的描述证明过程，我们用一个具体的例子来证明

记集合 \(S\) 为下面的 DFA 的语言

记集合 \(T\) 为

\[ T =\{w \in \{0,1\}∣w \text{ 不包含连续两个 1}\} \]

证明 \(S = T\) 的一种思路是证明它们互相包含：

♦ \(S \subseteq T\)

我们希望证明：如果 \(w\) 被 DFA 接受，则 \(w\) 没有连续的 \(1\)

然而“\(w\) 被 DFA 接受”这个假设太弱，在进行具体的归纳时不方便针对具体的接受情况讨论。为了让假设本身包含更多和 DFA 相关的内容，我们引入一个重要的技巧：加强归纳假设

IH：

（1）如果 \(\delta(A, w) = A\)，那么 \(w\) 没有连续的 \(1\)，并且也不以 \(1\) 结尾；

（2）如果 \(\delta(A, w) = B\)，那么 \(w\) 没有连续的 \(1\)，并且以单个 \(1\) 结尾

容易证明它严格强于原归纳假设，这就是加强归纳假设的核心

Basis：当 \(|w| = 0\) 时（\(w = \epsilon\)），满足 \(\delta(A, \epsilon) = A\)。显然它满足假设（1）的前件，并且没有连续的 \(1\)，不以 \(1\) 结尾；同时它不满足假设（2）的前件。所以完整的假设为真

Inductive：假设所有长度都小于 \(k\) 的字符串满足上述假设，那么对于任意长度等于 \(k\) 的字符串 \(w\)，我们令 \(w=xa\)，其中 \(a\) 是最后一个字符，\(x\) 是前面的部分。根据归纳，\(x\) 满足 IH 性质

  • 如果 \(\delta(A, w) = A\)，分析 DFA 发现，它的前一步只能是 \(A\) 或 \(B\)，并且 \(a = 0\)。因此 \(w\) 没有连续的 \(1\)，并且也不以 \(1\) 结尾
  • 如果 \(\delta(A, w) = B\)，分析 DFA 发现，它的前一步只能是 \(A\)，并且 \(a = 1\)。根据 \(x\) 的性质，它没有连续的 \(1\) 并且也不以 \(1\) 结尾，这使得 \(w\) 也不会存在连续的 \(1\)，并且以单个 \(a=1\) 结尾

以上，所有被 DFA 接受的 \(w\) 都没有连续的 \(1\)，\(S\subseteq T\)


♦ \(T \subseteq S\)

不妨证明逆否：如果 \(w\) 不被 DFA 接受，则 \(w\) 一定存在 \(11\)

为什么不对 \(S\subseteq T\) 的证明进行逆否化

逆否化会使得 DFA 的相关信息不再是我们的已知条件，显然 DFA 的信息量比“\(w\) 存在连续 \(1\)”的信息量大得多，因此逆否化之后对 \(x\) 的分类讨论过程会更长

由此也可以进一步解答为什么不在 \(T\subseteq S\) 的证明中使用加强归纳假设：“不被接受”只有落到 C 这一种状态，而抵达它的状态转移也是明确且唯一的，因此没有必要再针对不同的状态转移进行加强

总的来说，哪一边的信息更具体，就把哪一边作为已知条件，并通过逆否化、加强假设等方式获得更详细的信息

换言之我们只需要证明：

\[ w \notin L(A) \iff \delta(A, w) = C \]

根据 DFA 图，\(C\) 不会再抵达其他状态，从其他状态进入 \(C\) 的唯一方式是在 \(B\) 状态读入 \(1\)，而抵达 \(B\) 的唯一途径是从 \(A\) 状态读入 \(1\)，因此可以将 \(w\) 写成 \(x1y\) 的形式，有：

\[ \delta(A, x1y) = C \]

其中 \(y\) 是随意的后续字符串，而

\[ \delta(A, x) = B \]

在 \(S\subseteq T\) 的证明中，有

如果 \(\delta(A, w) = B\)，那么 \(w\) 没有连续的 \(1\)，并且以单个 \(1\) 结尾

因此 \(x\) 可以进一步写成 \(z1\) 的形式，那么 \(w\) 一定满足下面的结构

\[ w = z11y \]

因此 \(w\) 一定存在 \(11\)

以上，我们给出了 \(S=T\) 的完整证明

简单来说证明 \(S = T\) 即证明 \(S⊆T, T⊆S\)，一般的证明方法为：

通过逆否化命题等方式让 DFA 的信息作为一致结论，让数学描述成为待证明的性质

寻找“不定式”，即对每个状态 \(q\) 寻找特定的性质 \(R_q(w)\)，使得

\[ \delta(q_0,w)=q \implies R_q(w) \]

必要时可以加强归纳假设

\[ \forall w,\ \forall q,\quad \delta(q_0,w)=q \implies R_q(w) \]

然后对 \(|w|\) 进行归纳，分类讨论得到结论

NFA

NFA 与 DFA 不同的地方在于，转移行为是不确定的：NFA 在某个状态下，对同一个输入可能有多个下一状态，甚至是空转移（不需要读入符号就进行转移，我们称包含空转移的 NFA 为 ε-NFA）

举例

我们判断一个字符串中是否以 awa 结尾，那么 DFA 的模型应该是：

而 NFA 模型是非确定性的，只需要存在路径即可

（对于输入的某个 a，它可能参与构成最后的 awa，也可能不是。所以 nothing 状态对于输入 a 有两条分支，一旦走进了 Saw a 的分支，说明它就是 awa 结尾的第一个字母）

注意：一个包含 awa 但不以 awa 结尾的字符串不会被接受，因为即使某条路线能够到 Saw awa 状态，后续因为仍有输入，状态转移只能走向 dead state（省略未标明）

类比 DFA 的状态转移函数 \(\delta: Q \times \Sigma \to Q\)，NFA 转移结果是关于 \(Q\) 的子集合，即

\[ \delta: Q \times \Sigma \to 2^Q \]

对应的，NFA 也需要扩展转移函数：

\[ \hat{\delta}(q, \epsilon) = \{q\} \\ \hat{\delta}(q, wa) = \bigcup_{p \in \hat{\delta}(q, w)} \delta(p, a) \]

读入字符串 \(wa\) 后可能到达的状态 = 读入 \(w\) 后可能到达的每个状态，再读入 \(a\) 后可能到达的状态的并集

NFA 接受字符串的条件是：只要存在任一路径可以到达接受状态，则字符串是可接受的。NFA 的语言为这样的字符串集合

\[ \hat{\delta}(q_0, w) \cap F \neq \emptyset \]

因此可以这样描述 NFA 的语言

\[ L(M) = \{w \in \Sigma^* \mid \hat{\delta}(q_0, w) \cap F \neq \emptyset\} \]

Proofs of FA Equivalence

直觉上，同一个数学描述既可以用 DFA 建模，也可以用 NFA 建模。DFA 的优点在于可以机器实现，NFA 的优点在于建模直观，状态数少

考虑自动机等价，指他们仅接受完全相同的语言。我们考虑证明：对于一个 DFA / NFA，总能找到与他等价的另一类有限状态机 $$ L(D) = L(N) $$ ♦ DFA → NFA

显然，任何 DFA 都可以看成一个特殊的 NFA，只需要把 $$ \delta_D(q,a) = p $$ 改写成 $$ \delta_N(q,a) = {p} $$ 这样 NFA 的每一步结果都是一个单元素集合，行为与 DFA 完全一致

♦ NFA → DFA

我们引入子集构造法，让任意 NFA 都能转化为等价的 DFA

既然 NFA 读入字符串后可能处于一个状态集合，那么我们可以将这个状态集合打包成一个状态。这使得 NFA 的状态 \(Q\) 可以映射到另一个 DFA 的状态 \(2^Q\)
