图流算法

考虑一个图的数据是流式给出的（在线，且意味着算法不能 re-read），我们希望用有限小的数据结构（摘要），在不建模完整图历史的情况下，对图的相关属性进行处理记录与近似查询

抽象数据结构相比较完整图结构，更适合放在更快的内存中访问，并且通常具有更小的访问时间复杂度

代价是算法必须支持 Dynamic 的输入，只能使用摘要信息而不是完整的图，像 PageRank 这样的全局算法就无法使用

简单来说：静态数据 + 动态更新 = 流式算法

比如顶点集是预先给出的固定集（Insert），而更新流（Insert & del）是流式的操作序列，并且保证 del 操作合法（Strict Turnstile）。我们记 \(G_t\) 是这个图在 \(t\) 时刻的快照

而流式算法是一个有限的状态存储，每读取一个输入则进行状态更新，在输入完毕之后可以从存储中解码给出一个输出

对于一个默认模型，通常 \(G\) 是无向简单图，数据流仅允许按序访问一次，并且可以使用公共的随机数表辅助决策（这个表不计入内存开销）

Semi-streaming

Stream 可能是庞大的，我们希望算法的工作空间依赖于固定点集大小 \(n\)，即它是 \(O(n\log^c n)\) 的，而不能和输入流相关。而另一方面，算法不可能用这样的近似线性空间去精确回答所有问题，因此必须给出 \((\varepsilon, \delta)\) 近似：

\[ \forall G, \quad P(f_{out}\in [(1-\varepsilon)f(G), (1+\varepsilon)f(G)]) \geq 1 - \delta \]

即估计值以至少 \(1-\delta\) 的概率落在真实值的 \((1±\varepsilon)\) 倍区间内，这需要对最坏情形也成立

以上，内存的流无关开销为可行性，近似算法满足上述不等式为可靠性

Applications

给出一些图流算法的典型运用

Count Triangles

输入一个图 \(G\)，要求计数图中三角形的个数。数三角形需要找出所有的成环三元顶点组，存储完整图的代价至少是 \(\Omega(n^2)\)

为了简化问题，只考虑 Insertion-Only 的情况，即不涉及删除

在流式环境中，我们无法存储所有边，我们考虑对边进行 \(q\) 比例的随机采样

注意到一个三角形的形成的决定因素是它的最后一条边 closing edge（流式输入决定了一个三角形的三条边存在到达顺序，在最后一条边到达之前，无法判断这会是一个三角形），我们只在这条边到达时计数三角形，通过记录指示变量来确定三角形的前两条边是否被找到：

  • \(a \in \mathcal{T}\)，其中 \(a\) 是任意一个三角形

  • \(l(a)\) 是一个指示变量，指示前两条边是否被采样

一方面，根据独立同分布，每条边被采样的概率为 \(q\)，前两条边同时被采样的概率为 \(q^2\)，则

  • \(E[l(a)] = q^2\)

  • 记 \(X = \sum_{a\in\mathcal{T}} l(a)\) 是所有被采样的“三角形前两条边”的计数， 估计三角形总数 \(T_{est} = X/q^2 = \dfrac{1}{q^2} \sum_{a\in\mathcal{T}} E[l(a)] = T_{rel}\)

因此估计具有无偏性

我们得到无偏估计量 \(Y(a) = l(a) / q^2\)，现在考虑总方差

\[ \text{Var}\left( \sum_{a} Y(a) \right) = \sum_{a} \text{Var}(Y(a)) + \sum_{a \neq b} \text{Cov}(Y(a), Y(b)) \]

由个体方差与协方差共同决定

先看第一项，考虑 \(l(a)\) 是伯努利随机变量，\(l(a) \sim B(q^2)\)，则

\[ \text{Var}[l(a)] = q^2(1-q^2) \\ \text{Var}[Y(a)] = \dfrac{1}{q}-1 \\ \sum_{a\in\mathcal{T}} \text{Var}[Y(a)] \approx \dfrac{T}{q^2} \]

因此，即使这 \(T\) 个三角形互不相交，单项总差依旧与 \(T/q^2\) 成正比

接下来考虑协方差：考虑两个三角形 \(a,b\)，我们知道三角形共享某一条边 \(e\) 会导致协方差，考虑 \(Y(a)Y(b)\ne 0\) 当且仅当两个三角形的前两条边都被采样，则

\[ E[Y(a)Y(b)] = \dfrac{q^3}{q^4} = \dfrac{1}{q} \]

协方差计算得到

\[ \text{Cov}(Y(a),Y(b)) = E[Y(a)Y(b)] - E[Y(a)]E[Y(b)]= \dfrac{1}{q} - 1 \]

总方差是如何因采样率的减小而放大的？我们定义 \(\Delta E\) 为包含同一条边的三角形数量的最大值，考虑总方差的计算

\[ \text{Var}\left( \sum_{a} Y(a) \right) = \sum_{a} \text{Var}(Y(a)) + \sum_{a \neq b} \text{Cov}(Y(a), Y(b)) \]

每个共享的边会产生协方差，总共有约 \(T\Delta E\) 对这样的三角形，单项对总方差的贡献约为 \(\dfrac{1}{q}\)，使得总贡献约为 \(\dfrac{T\Delta E}{q}\)，我们发现这比个体方差 \(\dfrac{T}{q^2}\) 更大

以上我们得到总方差的上界

\[ \text{Var}(T_{est}) = O \left( \dfrac{T}{q^2} + \dfrac{T\Delta E}{q} \right) \]

为了获得有意义的近似，我们需要标准差与真实值 \(T\) 同阶，即

\[ \sqrt{\text{Var}(T_{est})} = O(T) \]

这意味着个体方差与协方差都存在约束

\[ \dfrac{T}{q^2} \leq T^2 \text{ and } \dfrac{T\Delta E}{q} \leq T^2 \]

因此

\[ q = \Omega\left( \max\left\{ \frac{1}{\sqrt{T}}, \frac{\Delta E}{T} \right\} \right) \\ \text{Space} = O(mq) = O\left( m \cdot \max\left\{ \frac{1}{\sqrt{T}}, \frac{\Delta E}{T} \right\} \right) \]

Connectivity

输入一个图 \(G\)，输出所有的连通分量（以生成森林的方式）

假设流式输入是 Insertion-Only 的，那么并查集可以高效解决问题。然而，如果引入删除操作，问题会变得复杂

我们先从这样的问题开始：

1-稀疏场景

考虑一个图的两个不相交顶点集 \(A, B\)，初始有边集合 \(\delta(S)\) 是跨越两个顶点集的边。在抽象数据结构下，我们不知道到底有多少条边连接了这两个集合

下一步，对 \(\delta(S)\) 的部分边进行删除，直到只剩下 \(e^{\ast}\) 这一条边。我们称之为 1-稀疏场景。在抽象数据结构下，我们不知道此时这条边的存在性，以及它是哪一条

我们希望恢复出唯一的 \(e^{\ast}\)，因此给出支持集查找：

  • 将数据抽象为长度为 \(n\) 的整数向量 \(x\)

  • 对于每一次更新 \(update(i, ±1)\)，我们设定 \(x_i \leftarrow x_{i} ± 1\)

    • \(\Delta = ±1\) 表示是插入 or 删除

  • 我们记更新完毕后，值不为 \(0\) 的索引 \(i\) 的集合为支持集

关键依旧在于数据结构的内存开销问题，以及单次扫描的约束。在此基础上，我们依旧要找出那个非零坐标 \(i\)，以及 \(x_i\) 的值 \(a\)

恢复 \(a\)

约定计数器 \(C_0 = \sum_{i=1}^{N} x_i\)，初始化为 \(0\)

在维护支持集时，令 \(C_0 \leftarrow C_{0} + \Delta\)

流结束后，根据 1-稀疏约定，\(C_0 = 0 + 0 + \dots + a + \dots + 0 = a\)

恢复 \(i\)

约定计数器 \(C_1 = \sum_{i=1}^{N} i \cdot x_i\)，初始化为 \(0\)

在维护支持集时，令 \(C_1 \leftarrow C_{1} + i\times \Delta\)

流结束后，根据 1-稀疏约定，\(C_1 = ia\)，\(i = \dfrac{C_1}{C_0}\)

验证

我们用有限域 \(\mathbb{F}\) 下的伪随机数 \(z_i\) 代替计算 \(C_i\) 时用到的 \(i\)

维护计数器 \(H := 0\)，每次更新时，也更新累加器 \(H \leftarrow H + \Delta \times z_i\)（\(\Delta = ± 1\)）

结束计算后，\(H = a\times z_i\)，因为只有 \(i\) 对应的 \(x_i\) 不为零，即 1-稀疏场景

因此正确情况下 \(a = H \div z_i\)（显然，\(a\) 需要是一个整数），进一步的可以算出 \(i\)

事实上这就是哈希处理，上述运算取有限域 \(\mathbb{F}\) 的模运算，上述做法通常用于计算验证

容错分析

上述算法基于 1-稀疏场景，事实上算法在非 1-稀疏场景可能会被抵消为 1 个，从而错误的通过验证

错误概率 \(e \leq \dfrac{1}{|\mathbb{F}|}\)，其中 \(\mathbb{F}\) 是验证随机数使用的有限域

通用场景

显然，通常情况下图结束不可能只有一条边，单个 1-稀疏解码器不能独立使用，我们考虑几何降采样：

  • 为每个坐标 \(i\) 分配 \([0,1]\) 的随机哈希值

  • 定义 \(S_l=\{i:hash(i)\leq 2^{-l}\}\)，任意坐标落在 \(S_l\) 的概率是 \(\dfrac{1}{l+1}\)

  • 每次传入 \((i, \Delta)\) 的更新时，判断这个坐标落在了哪几层。对于每一个落入的层 \(j\)，把更新指令喂给这一层的 1-稀疏解码器

  • 结束后，依次检查每个层 \(l\)，如果在 \(l\) 的 1-稀疏解码器中发现了合法非零值，则说明这一层恰好只有 \((j, x_j)\) 被保留

我们假设流式处理结束后，最终图中剩下 \(s\) 条边。我们希望在某一层 \(l\) 中可以稀释到只剩下一条。我们选择 \(l^{\ast} = \lceil \log_2 s\rceil\)，在这一层的保留概率为 \(p=2^{-l^\ast}\)，容易得到对数区间约束

\[ \dfrac{1}{2s} < p < \dfrac{1}{s} \]

在 \(l^{\ast}\) 中，每条边被保留下来的概率都是 \(p\)，则最后能在这个层级幸存下来的边的数 \(Y\) 满足二项分布

因此

\[ P[Y=1] = sp(1-p)^{s-1} \geq \dfrac{1}{2} \times \dfrac{1}{e} = \dfrac{1}{2e} \]

所以存在 1-稀疏层级的概率不小于常数 \(1/2e \approx 18.4\%\)

重复执行独立的分层结构 \(O(log(1/δ))\) 次可以放大算法的成功率

求出割集

现在，我们为所有的顶点 \(w\) 维护各自的向量，把图中每一条可能的边 \(e=\{u,v\}\) 都看作一个坐标，只更新它两个端点的向量：

  • 给顶点 \(u\) 的草图向量在坐标 \(e\) 上加 1，即 \(a_u[e]= +1\)

  • 给顶点 \(v\) 的草图向量在坐标 \(e\) 上减 1

如果我们要检查某一个顶点子集 \(S\)（一个割集）的所有跨越边，则

\[ \sum_{v \in S} \text{SF}(a_v) = \text{SF}\left( \sum_{v \in S} a_v \right) \]

对 \(S\) 中所有向量求和后得到的新向量 \(b(S)\)，它的支持集正好就是 \(S\) 的割集
