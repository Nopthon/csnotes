# 分布式计算

分布式计算相比串行计算，存在效率更高，稳健性强的特点

然而分布式计算也有缺陷：

- 单个机器通常不共享全局数据，只具有局部视野

     - 网络通信交换信息不是可靠的

- 对称性，即节点只能表现出一致的行为（相同的节点进程没有任何初始身份或状态的区别），无法通过确定性的算法选举出 Leader 节点

     - 需要打破对称，比如 ID 分配，引入随机算法

## 消息传递模型

抽象和建模一个分布式系统，采用图模型：处理器作为节点，双向通信链路作为边；研究分布式算法，本质上研究图上的节点如何通过边传递消息来完成某项任务

在同步模型下，我们离散化时间，采用回合制，使得所有节点都对每一个回合的开始和结束时间达成了一致（全局一致性，即对齐所有节点的行为）

然而这种该模型并不现实，现实世界中的通信存在延迟与波动，步调难以达成一致，因此我们需要给出异步模型：消息延迟是任意有限的

- 不同消息的延迟时间可能截然不同

- 每一条消息最终都会被送达

- 不知道最大的延迟是多少

异步模型需要引入复杂的机制，以下的主要内容均围绕同步模型

---

分布式算法的性能评估包含若干种衡量标准：时间复杂度、空间复杂度、通信复杂度、可行性

## Vertex Coloring

考虑之前提到的点着色问题，易知 $\Delta+1$ 种颜色可以完成对任意最大度为 $\Delta$ 的图的着色，并且实际的下界通常小得多

现在我们引入分布式约束：

- 每个节点只知道自身和邻接点

- 没有中央节点指挥，所有的节点对称，通过互相发消息完成分配

如果我们能完成这样的任务，把不同的颜色分配为发送信息的顺序，我们就得到了时分多址（TDMA）的时间表

---

我们先从网络拓扑为一棵有向有根树开始：如果节点知道自身的深度，则可以按照层数奇偶性进行 2-染色。然而分布式约束决定了节点不会天然知道自身深度

这里给出一种 6-着色的迭代算法：

- 为每个节点 $v$ 递增分配初始 ID，记标识符 $\phi_v$ 初始为 ID 值

- 每一轮，每个节点 $v$ 将当前的 $\phi_v$ 发送给它的子节点，然后：

     - 如果 $v$ 是根节点，则记中间变量 $I = 0$

     - 否则，我们比较 $v$ 和它的父节点的标识符，找出两者二进制表示中第一个不同的位设置为 $I$，即 $\min\{i \mid φ_v[i] ≠ φ_{parent(v)}[i]\}$

- 更新 $\phi_v = 2I+\phi_{v}[I]$

- 重复上述过程，直到所有节点的 $ϕ_v$​ 值都在集合 $\{0,1,2,\cdots,5\}$ 之间

每迭代一次，节点标识符的二进制位数都会显著减少，可以证明：

- 单轮迭代前后，$\phi_v$ 的比特占用数从 $x$ 下降到 $\lceil \log x \rceil + 1$

- 算法的运行时间是 $O(\log ^{\ast} n)$，这个值可以视为一个不超过 $5$ 的常数

## Consensus

考虑这样的一个问题：

- 每个节点都有一个初始值

- 每个节点在算法运行结束后输出同一个最终值

我们称之为共识问题，它满足以下性质：

- Termination：每个节点最终都必须输出一个值，并且停止等待

- Agreement：所有正常运行的节点，其最终输出的值必须完全相同

- Validity：最终达成一致的值必须来源于某个节点的初始提议值

进一步的，如果某些节点在某一时刻出现了崩溃故障（不响应），正常节点是否还能达成共识
